# Normal user

**Type:** Free play

A clean profile with nothing set and nothing learned. Use it to try your own messages.

## How to use it
1. Open the mirror and set any style you like (length, tone, sourcing, structure, revision).
2. Chat normally. Ask for things that agree with what you set, then things that don't.
3. Watch the tier pill on each answer (Nano, Super, Ultra) and read the routing reason under it.

## What to look for
- While what you ask matches what you said, every answer should stay on **Nano**.
- Once a contradiction repeats, the router escalates and names the dimension, for example
  *"Strongest dissonance: length (you said 'concise', you behave 'detailed', seen 2x, score 0.55)"*.
- 👍 and 👎 count as behaviour too.

Press **Start fresh** in Settings → Profile at any time for a new empty profile.
